2. Napište dekorátor, který používá funkce implementující obsluhu mazání záznamů z databáze.

Odpověď:
Aplikace používá dekorátor `login_required`, který zajišťuje, že mazání záznamu je přístupné pouze přihlášeným uživatelům.

```python
def login_required(view):
    @wraps(view)
    def wrapped_view(**kwargs):
        if not session.get("user_id"):
            return redirect(url_for("login"))
        return view(**kwargs)
    return wrapped_view
```

4. Jak jste vyřešili přístup uživatelů do aplikace?

Odpověď:
Aplikace má tabulku `users` v databázi, kde jsou uložena uživatelská jména a zahashovaná hesla. Při přihlášení uživatel zadá `username` a `password`, které se porovnají s databázovým záznamem. Po úspěšném přihlášení se do session uloží `user_id` a `username`, což umožňuje aplikaci rozpoznat přihlášeného uživatele.

5. Jakým způsobem ukládáte hesla?

Odpověď:
Hesla se neukládají v čistém textu. Při inicializaci databáze se jako výchozí uživatel uloží hash hesla vytvořený funkcí `generate_password_hash` z Werkzeugu, a při přihlášení se heslo ověřuje pomocí `check_password_hash`.

6. Jak je řešeno, že danou operaci, např. úprava záznamu, může provést pouze přihlášený uživatel? Vložte ukázku kódu, který to řeší.

Odpověď:
Operace jako úprava záznamu jsou chráněny dekorátorem `@login_required`, který přesměrovává nepřihlášené uživatele na stránku přihlášení.

```python
@app.route("/birds/<int:bird_id>/edit", methods=["GET", "POST"])
@login_required
def edit_bird(bird_id):
    with get_db() as conn:
        bird = conn.execute("SELECT * FROM ptaci WHERE id = ?", (bird_id,)).fetchone()
        if request.method == "POST":
            # aktualizace záznamu
            conn.execute(
                "UPDATE ptaci SET nazev=?, vedecky_nazev=?, rad=?, celed=?, delka_cm=?, rozpeti_cm=?, hmotnost_g=?, status_ohrozeni=?, typ_potravy=?, migrace=?, vyskyt_kontinent=?, snuska_ks=? WHERE id=?",
                data
            )
            flash("Upraveno.", "success")
            return redirect(url_for("bird_list"))
    return render_template("bird_form.html", bird=bird, form_action=url_for("edit_bird", bird_id=bird_id), title="Upravit ptáka")
```
