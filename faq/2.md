## Otázky a odpovědi

1. Napište vědecký název veškerého ptactva, které splňuje současně následující kritéria: vyskytuje se v Evropě, je téměř ohrožené a jsou hmyzožravci.

Odpověď:
- Coracias garrulus
- Numenius arquata
- Vanellus vanellus

2. Napište SQL dotaz, kterým lze získat informaci z předchozí otázky. Budete muset najít způsob, jak takový dotaz získat. Do odpovědi nevkládejte dotaz, který obsahuje proměnné.

Odpověď:
```sql
SELECT vedecky_nazev
FROM ptaci
WHERE vyskyt_kontinent = 'Evropa'
  AND status_ohrozeni LIKE '%téměř%'
  AND typ_potravy LIKE '%hmyz%'
ORDER BY vedecky_nazev;
```

3. Jak se do HTML šablony dostanou data o ptactvu, která si uživatel nechal vypsat s použitím filtru? Do odpovědi vložte volání funkce, kde se tak děje.

Odpověď:
Data jsou předána z view funkce `dashboard()` do šablony `dashboard.html` pomocí volání:

```python
return render_template("dashboard.html", ptaci=ptaci, ...)
```

4. Jakou JS knihovnu používáte pro zobrazování grafů? Odkud se stahuje?

Odpověď:
Aplikace používá knihovnu Chart.js pro vykreslování grafů. Knihovna se načítá z CDN pomocí odkazu:

```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```
